# Hello World

Welcome to the Mochi blog. Mochi is an SSR-first framework for Svelte 5 on Bun with islands-based selective hydration — and until now, everything we had to say about it lived in the [docs](/docs/intro/).

The docs are deliberately terse: what a feature does, how to use it, one example. That format has no room for the other half of framework work — why a feature is designed the way it is, what we learned building it, and what's changing underneath us in Bun and Svelte. That's what this blog is for.

Expect posts on Mochi internals (how the component registry compiles islands, how server islands encrypt their props), on the runtime we build on (Bun moves fast, and we ride along), and the occasional release retrospective.

If you're new to Mochi, start with the [docs](/docs/intro/) or poke at the live demos on the [home page](/). See you in the next post.
